# Heartz Band — Página web oficial

Página web de Heartz Band, hecha solo con HTML y CSS para el Laboratorio de Programación Web.

**Ver la página:** https://emmxnueo.github.io/heartz-band-v2/

## Secciones

- **Inicio:** carrusel de fotografías con flechas, animación de entrada del logotipo y enlace a Instagram.
- **Menú:** Biografía, Galería y Contacto.
- **Galería → Eventos:** cuadrícula de fotografías que se abren en grande y se recorren con flechas.

Biografía y Contacto estarán disponibles próximamente.

## Cómo abrirla

Abrir la carpeta en Visual Studio Code y elegir **Open with Live Server** sobre `index.html`, o abrir `index.html` directamente en el navegador.
